Supernova Backup

A private backup connection for the site owner's own files.

Supernova Backup uses rclone to copy selected files from the owner's computer systems to the owner's Google Drive. It supports scheduled backups and removal of older backup copies under the owner's retention settings.

Google Drive access

The connection requests permission to see, edit, create and delete Google Drive files. This allows it to manage backup folders and older copies. That permission is broader than the intended backup use: Google does not limit this permission to a single backup folder.

Only the owner is intended to connect an account. This website is an information page; it does not provide access to backups or ask visitors to sign in.

Data and control

Backup contents and account credentials are kept outside this public website. The owner controls the connection, backup selection and retention settings. Read the privacy policy and terms of use for details.
